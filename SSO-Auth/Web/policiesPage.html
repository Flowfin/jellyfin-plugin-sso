A named starting policy that any number of providers can share. A provider points at one by name in its own Starting policy section; a provider that names none keeps its own inline policy instead, and the two are mutually exclusive. Every field here follows the same rules as the inline version: anything left alone keeps Jellyfin's own default, zero is a real value for the two numbers, and the values are written once, when an account is created.
The profiles this configuration defines. Choosing one loads it into the fields below; Save profile writes it back.

The name a provider points at. Add profile creates a new one under this name; Rename profile renames the profile selected above and repoints every provider and role rule that names it, so nothing is left pointing at a name that no longer exists.
A new profile begins as what a provider does today, so the first edit is a difference from a known state rather than a form filled from blank. Only providers that carry an inline policy are listed. Choosing to start empty is allowed and means exactly that: until you set a field, the profile writes nothing onto a new account.
The remote streaming ceiling in bits per second. Zero means no limit, which is a real setting rather than an empty one. Leave blank to keep Jellyfin's own default.
How many sessions the account may hold at once. Zero means unlimited, which is a real setting rather than an empty one. Leave blank to keep Jellyfin's own default.
The language code Jellyfin itself stores, for example eng. It is passed on as given rather than checked against a list, so any code Jellyfin accepts works. Leave blank to keep Jellyfin's own default.

Permissions written onto a new account

Each row names one Jellyfin permission and the value a new account starts with. A permission that is not listed is never touched. The names come from the server rather than from a list kept on this page, so they cannot drift from what a save accepts; administrator, all-folders and Live TV access are not offered here because each keeps its own setting above, and no account can be created disabled from here.
