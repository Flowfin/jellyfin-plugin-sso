Full text
Every Jellyfin account that holds an SSO link, with the provider and the identity-provider subject behind each link. Revoking an account removes its links from every provider and ends every session it holds on every device. It also switches the account back to the built-in Jellyfin password provider, so it can use a password again; the server-wide setting is not changed. A revoke is not durable where a provider has Allow Existing Account Link enabled: the same-named account can be re-adopted on its next SSO login. Disable or rename the local account as well when the cut has to hold. Requires administrator privileges.

Accounts this plugin created disabled because their provider provisions new users disabled, and that are still waiting. Approving enables the account and changes nothing else: its permissions are the ones the provisioning gave it. An account that an administrator disabled is not listed here, whatever its state, and is enabled in the Jellyfin dashboard. Read together with the linked accounts above; Refresh Linked Accounts re-reads both.

Export / Import Account Links

Full text
Account links are stored against Jellyfin user ids, which a rebuilt user database does not reissue. A migration therefore needs this second file beside the configuration file above. It is keyed on usernames and is not redacted: it holds usernames and the provider subject behind each link, so treat it as identity data. Import restores every link onto the account this server holds for that username today. A file naming a user or provider this instance lacks, or a link already held by another account, is rejected whole. Requires administrator privileges.
