Who uses this profile

A profile with no user is a profile nobody is maintaining, so the tab says which providers point at it.

  • keycloak - Starting policy
  • entra - Starting policy
  • okta overrides it inline, so this profile does not reach it

What a profile does not carry

It is the policy an account STARTS with. Changing it later does not reach accounts that already exist, which is the sentence the page has to say where the profile is edited rather than in a note further down.
